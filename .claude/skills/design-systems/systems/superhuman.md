# Design System: Superhuman

## 1. Visual Theme & Atmosphere

Dramatic purple gradient hero (#1b1938) contrasting with white content. Maximum confidence through minimum decoration. Product screenshots as primary visual content.

- Hero: Mysteria Purple #1b1938
- Super Sans VF (custom variable font)
- Non-standard weights: 460, 540, 600, 700
- Display compression: 0.96 line-height
- Binary radius system: only 8px and 16px
- Single accent color, minimal decoration

## 2. Color Palette

| Role | Color | Hex |
|------|-------|-----|
| Hero BG | Mysteria Purple | #1b1938 |
| Primary Text | Charcoal Ink | #292827 |
| Accent | Lavender Glow | #cbb7fb |
| Button BG | Warm Cream | #e9e5dd |
| Borders | Parchment | #dcd7d3 |
| Link | Amethyst | #714cb6 |

## 3. Typography

Font: Super Sans VF (variable)

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Display Hero | 64px | 540 | 0.96 |
| Heading | 40px | 540 | 1.10 |
| Sub-heading | 24px | 540 | 1.20 |
| Body | 16px | 460 | 1.50 |
| Caption | 14px | 460 | 1.40 |

## 4. Components

**Buttons**: 8px radius, Warm Cream (#e9e5dd) bg, no borders
**Cards**: 16px radius, 1px Parchment border, white bg
**Links**: underlined, Amethyst #714cb6

## 5. Layout

Max width: ~1200px. Base: 8px.
Radius: ONLY 8px and 16px (binary system).
Section padding: 48-80px vertical.
Breakpoints: <768px, 768-1024px, 1024-1440px, >1440px
