# Awesome DESIGN.md Repository

**Repository URL:** https://github.com/VoltAgent/awesome-design-md

## Overview

A curated collection of DESIGN.md files extracted from popular websites. The concept represents "a plain-text design system document that AI agents read to generate consistent UI." Each DESIGN.md file is markdown-based with no special tooling required.

## Purpose

Copy a DESIGN.md into your project and tell your AI agent to build UI that matches it for pixel-perfect, consistent interfaces. DESIGN.md is optimized for how LLMs read and process design specifications.

## Standard File Structure

Each entry includes three components:
- **DESIGN.md** — The design system document
- **preview.html** — Visual catalog with colors, typography, components
- **preview-dark.html** — Same catalog with dark-mode surfaces
